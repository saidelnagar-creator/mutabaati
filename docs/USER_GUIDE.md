# دليل الاستخدام

## أول مرة
1. افتح الرابط من Safari ← مشاركة ← «إضافة إلى الشاشة الرئيسية» (التفاصيل في [DEPLOY.md](DEPLOY.md)).
2. المزيد ← الإعدادات ← **تفعيل القفل** (رقم 4–8 أرقام)، واكتب اسمك في رأس التقرير لو حابب.
3. المزيد ← النسخ الاحتياطي ← فعّل Google Drive (كلمة سر التشفير إجبارية — احفظها برّه الموبايل).

## مريض جديد
- **المرضى ← مريض جديد**: الاسم، النوع، السن (تاريخ ميلاد أو السن بس)، التليفون، البلد، المصدر (المعهد/معارف البلد/…)، ومصدر معرفته بيك.
- **بداية المتابعة**: «بيبدأ دلوقتي»، يوم، شهر، سنة، «من حوالي…»، أو «مش فاكر». وقت التسجيل بيتسجل لوحده.
- **التصنيف**: نوع السكر وتاريخ التشخيص (مدة المرض منفصلة عن متابعته معاك).
- **علاج كان بياخده**: من تبويب العلاج ← «+ علاج كان بياخده» (التاريخ ممكن يكون مش معروف).

## كل متابعة
- **متابعة**: الشكوى (بتشوف اللي فاتت وتختار: زي ما هي/أحسن/أسوأ/خلصت/جديدة)، الوزن والضغط، القراءات، التقييم والخطة.
- في نفس النموذج: **الميعاد الجاي**، **التحاليل المنتظرة** وميعاد نتيجتها، و**أسأله عن**.
- **تحاليل**: اختار مجموعة (سكر، كلى، كبد، دهون…) واكتب النتيجة بالوحدة اللي في الورقة. التحاليل المنتظرة بتتقفل لوحدها.
- **دواء**: ابحث بالاسم التجاري أو العلمي ← التركيز ← المواعيد والكمية والعلاقة بالأكل. التنبيهات بتظهر قبل الحفظ.
- **تعديل الجرعة / إيقاف**: من بطاقة الدواء، بالتاريخ والسبب.
- **السكر**: جدول قراءات البيت (أيام × مواعيد)، تقرير CGM، نوبة هبوط.
- **التصنيف**: الحالات المصاحبة (حمل، CKD، تليف، HF، تاريخ بنكرياس/MTC، …) — ولها تاريخ انتهاء (الولادة مثلاً).

## التنبيهات
ممنوع • تجنّب • تعديل جرعة • حذر • متابعة • مُوصى به • معلومة. كل تنبيه بسببه والبديل والمرجع.
«تمت المراجعة» يخفيه للمريض ده. «تعديل القاعدة» يفتح القاعدة: عدّل الحد (مثلاً eGFR) أو النص أو اقفلها.

## التقارير
ملف المريض ← «تقرير»: كامل أو مختصر (إنجليزي) أو تعليمات المريض (عامية/فصحى) ← طباعة/PDF أو مشاركة كملف.
المزيد ← التقارير: إحصاءات وتصدير Excel.
