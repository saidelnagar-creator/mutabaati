# سجل التغييرات

## 0.1.0 — المرحلة 1أ (السكر)
- المرضى: المصدر ومصدر المعرفة، بداية المتابعة بدقة متغيرة، نوع السكر ومدته، الحالات المصاحبة بتواريخ وأكواد ICD-10.
- المتابعات: الشكوى وتطورها، القياسات، التقييم والخطة، الميعاد الجاي والتحاليل المنتظرة والأسئلة.
- التحاليل: 68 تحليل بمجموعات ووحدات بديلة، جدول مقارنة ورسم، eGFR/FIB-4/Non-HDL/LDL/eAG/UACR/HOMA/TyG محسوبة.
- العلاج: مكتبة 112 مادة فعالة و105 اسم تجاري (قابلة للتعديل والإضافة)، بناء الجرعة والعلاقة بالأكل، خط زمني كامل.
- التنبيهات: 117 قاعدة (الكلى، الكبد، الحمل، السن، HF، التكرار، الفجوات العلاجية) قابلة للتعديل والقفل والإضافة، ومراجعة لكل مريض.
- السكر: قراءات البيت، CGM مقابل الأهداف، الهبوط.
- الحاسبات (15)، المتابعات الدورية حسب ADA، التقارير (كامل/مختصر/تعليمات/Excel).
- النسخ: Drive مشفر تلقائي، تصدير مشفر بالصور أو من غيرها، المرآة الداخلية، النسخ التلقائية، القفل.
