# النشر والتثبيت

## مرة واحدة على GitHub
1. الريبو `mutabaati` ← **Settings ← Pages ← Build and deployment ← Source: GitHub Actions**.
2. أي دفع على `main` يشغّل الاختبارات ثم ينشر مجلد `app/` على:
   `https://<اسم-المستخدم>.github.io/mutabaati/`

## على الآيفون
1. افتح الرابط من **Safari** ← زر المشاركة ← **إضافة إلى الشاشة الرئيسية**.
2. افتح التطبيق من الأيقونة مرة وأنت متصل بالإنترنت (عشان يتخزن للأوفلاين).
3. فعّل القفل والنسخ على Drive.

## Google Drive (اختياري، مستحسن)
من المزيد ← النسخ الاحتياطي ← «تفعيل النسخ على Drive» — الخطوات مكتوبة جوه التطبيق (Client ID مجاني من Google Cloud، والـ redirect URI هو رابط التطبيق بالظبط).

## تحديث التطبيق
كل نسخة جديدة بتظهر «تحديث الآن». البيانات مش بتتأثر.

> ⚠️ تغيير اسم الريبو أو المستخدم = رابط جديد = تطبيق فاضي على الموبايل. لو لازم: صدّر نسخة احتياطية الأول.
