# الأمان وحماية بيانات المرضى

| | |
|---|---|
| البيانات | على الموبايل فقط (IndexedDB). لا خادم ولا قاعدة بيانات على الإنترنت. |
| الريبو والموقع | كود فقط. فتح الرابط من جهاز تاني = تطبيق فاضي. |
| الاتصال الخارجي | لا شيء افتراضياً. CSP تمنع أي كود أو اتصال خارجي إلا `www.googleapis.com` للنسخ على Drive لو فعّلته بمعرّف عميلك. |
| القفل | رقم 4–8 أرقام (بصمة مملّحة ومكررة)، انتظار متضاعف بعد 5 محاولات خاطئة، قفل تلقائي بعد دقيقتين في الخلفية، وزر قفل فوري. |
| النسخ الاحتياطي | مشفر **إجبارياً**: AES-256-GCM بمفتاح PBKDF2 (250 ألف دورة). لا استرجاع لكلمة السر. |
| Drive | صلاحية `drive.file` فقط (التطبيق يشوف ملفاته بس). ملف للسجل وملف منفصل للصور (اختياري). |
| الصور | مضغوطة على الجهاز، في مخزن منفصل، وتدخل النسخة فقط لو اخترت «بالصور». |
| ملفات التقارير و Excel | فيها بيانات مرضى غير مشفرة — احفظها في مكان آمن. |

## ضد الضياع
| الخطر | الحماية |
|---|---|
| خطأ إدخال | لا شيء يُمحى: الإلغاء والتعديل قيود جديدة بسبب مكتوب. |
| استيراد/استرجاع/ترقية | نسخة تلقائية قبلها (آخر 12)، والعملية ذرية. |
| تلف قاعدة البيانات وحدها | نسخة مرآة داخلية + عرض الاسترجاع عند التشغيل. |
| فقد الموبايل | **نسخة خارجه فقط**: Drive التلقائي أو التصدير. |

## عليك
رمز دخول و Face ID على الموبايل • قفل التطبيق • Drive مفعّل • كلمة سر النسخ محفوظة برّه الموبايل • التحقق بخطوتين على GitHub و Google.
