# متابعاتي

تطبيق ويب تقدّمي (PWA) عربي لطبيب الغدد: متابعة المرضى من العيادة والمعهد ومعارف البلد. المرحلة الأولى: **السكر**.

- يُثبَّت على iPhone من Safari ويعمل بدون إنترنت.
- **بيانات المرضى على الموبايل فقط** (IndexedDB). المستودع ده **كود فقط** من غير أي بيانات.
- كل نسخة احتياطية مشفرة إجبارياً بكلمة سر (AES-256) — Google Drive تلقائي أو ملف يدوي، بالصور أو من غيرها.

## المرحلة 1أ (الحالية)

| | |
|---|---|
| المرضى | المصدر ومصدر المعرفة، بداية المتابعة بدقة متغيرة (يوم/شهر/سنة/تقريبي/مش فاكر)، نوع السكر ومدته |
| المتابعات | الشكوى وتطورها، القياسات، التقييم والخطة، الميعاد الجاي والتحاليل المنتظرة والأسئلة |
| التحاليل | بالوحدة اللي في الورقة (تحويل SI تلقائي)، جدول مقارنة ورسم، eGFR و FIB-4 و LDL محسوبين |
| العلاج | علمي أو تجاري أو مضاف، تركيبات، العلاقة بالأكل، خط زمني (قبل متابعتي/بدء/تعديل/إيقاف) |
| التنبيهات | الكلى، الكبد، الحمل، السن، HF، التداخل والتكرار، وفجوات العلاج — بالبديل والمرجع، وكلها قابلة للتعديل |
| السكر | قراءات البيت التفصيلية، تقارير CGM مقابل الأهداف، سجل الهبوط |
| الحاسبات | eGFR (CKD-EPI 2021)، CrCl، KDIGO، BMI/IBW، FIB-4/NFS/APRI، Child-Pugh، MELD، HbA1c↔eAG/GMI، LDL، DKA/HHS، QTc، الإنسولين، HOMA |
| التقارير | تقرير كامل/مختصر (PDF)، تعليمات المريض بالعربي، Excel، تقارير عامة |
